# Changelog

## 0.1.1 — Unreleased

## 0.1.0 — Unreleased

- Inspect enforced/report-only CSP headers and HTML CSP meta tags.
- Show complete HTTP response headers, redirect hops, HTTP version and remote address.
- Inspect TLS leaf certificates, including SANs, validity dates, readable expiry, fingerprint and PEM.
- Probe negotiated TLS version, cipher suite, ALPN and key-exchange group on a separate direct connection.
- Support private CA bundles, custom request headers, proxy settings, JSON and terminal colours.
- Include mise tasks, CI checks, draft release packaging and a Homebrew formula template.
